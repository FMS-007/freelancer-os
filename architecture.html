// 02 — CORE COMPONENTS

Three-Layer Architecture

Each layer has a single responsibility. Extension scrapes. Backend processes. Frontend displays. No logic bleeds between layers.

🔌
Chrome Extension
Source of Truth — Controls Everything
  • Upwork: RSS feed + DOM scraping
  • Freelancer.com: Direct API integration
  • Real browser session / cookies — bypasses Cloudflare
  • Configurable keywords & platform filters
  • Auto-scraping with schedule control (Chrome Alarms)
  • POSTs results to backend via HTTP
  • background.js — persistent MV3 service worker
  • Content scripts injected into platform pages
background.jspopup.jsupwork-scraper.jsfreelancer-scraper.js
⚙️
Backend API
Node.js · Express · Prisma · Redis
  • Receives raw scraped data from extension
  • 24h timestamp filter — missing timestamp = reject
  • Payment & profile verification filters
  • Rating, reviews & keyword AND-logic filters
  • Deduplication via Redis ID cache
  • PostgreSQL persistence via Prisma ORM
  • Groq AI integration for proposal generation
  • JWT + OTP email authentication system
ExpressPrismaRedisGroq AIPostgreSQLTypeScript
🖥️
Web Dashboard
React · TypeScript · Vite · Tailwind
  • Dashboard — stats & activity overview
  • Automation — mirrors extension state in real-time
  • Find Projects — filtered, live project listings
  • AI Analyze — Groq-powered project insights
  • Records — historical project database
  • Settings — filters, keywords, user preferences
  • Auth: Login / Signup / OTP / Reset Password
  • Never implements independent scraping logic

// 08 — DEPLOYMENT ARCHITECTURE

Server & Deployment Structure

Three independent deployment targets. Frontend is a static SPA. Backend is a Node.js service. Extension is Chrome Web Store distributed.

🌐 Client Layer
React SPA (Vite Build)Static HTML/JS/CSS — served via CDN or static hosting (Vercel / Netlify). Zero server-side rendering.
Chrome Extension (MV3)Distributed via Chrome Web Store. Sideloaded in dev. Auto-updates via CWS manifest.
Browser SessionExtension uses existing Upwork / Freelancer login cookies — no credential storage needed.
⚙️ API Server Layer
Node.js / ExpressRuns on VPS (DigitalOcean / Railway / AWS EC2). Port 3000 internally.
PM2 Process ManagerKeeps Node.js alive with auto-restart on crash, zero-downtime reloads.
Nginx Reverse ProxySSL/TLS termination, HTTPS redirect, proxies to Node.js app.
CORS ConfigLocked to frontend origin + extension ID. Rejects unauthorized origins.
💾 Data Layer
PostgreSQLManaged DB (Supabase / Railway / RDS). Persistent storage with Prisma migrations.
Redis InstanceIn-memory cache for dedup IDs, rate limiting, and JWT refresh tokens.
Environment VariablesAll secrets in .env — never committed. Managed via hosting platform secrets vault.
